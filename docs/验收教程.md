# 验收教程：路线① 导航侧 × Agnes Harness（AGH）

**这篇教程让你（或评委）从零到"确认整条链路可用"**，全过程约 40 分钟；其中用真实 key 的模型复验约 10 分钟 + 一轮真实会话。
所有步骤都给出了命令、期望输出、以及**不通过时怎么定位**。原则：**只认可核对的证据，不认叙述**。

## 2. 数据面验收（5 分钟）

数据面是唯一的取数实现，工具、看板、报告都走它。**不带子命令**会打印一份速览（环境 + 最近 5 个 run + 五套配置的头条数字），
完整子命令看 `--help`。逐条跑，对照"期望"里的关键字段：

| 命令（前缀 `PYTHONPATH=/srv/agh-demo/src $PY $B/bin/agh_nav_probe.py`） | 期望中的关键字段 |
| --- | --- |
| （不带子命令） | `command: "quick"`，含 `status/runs_available/latest_runs/board_headline` |
| `status` | `route1_importable: true`、`runs_available ≥ 15`、GPU 与 tmux 列表 |
| `runs` | 15 个 run；`r1grd4` 的 `pooled_success≈0.75`、`r1ro4c≈0.6538` |
| `board` | `configs` 含 5 个键；`scenes` 8 个；`recovery_only.pooled_success=0.6635` |
| `run-summary --run r1grd4` | `official_label_coverage≈0.15`；`replan_reasons` 里同时有 `collision_density_replan` 与 `progress_stall_replan` |
| `triggers --run r1grd4` | `official_label_p@1.p_at_k = 0.0`（这是本项目最重要的负结论之一） |
| `recovery --run r1grd4` | `channels.implementation` 含 `route1.nav.channels`；`failed_episodes_covered=12`（共 13） |
| `failures --run r1grd4 --limit 3` | 事件带 `id/source=nav/type/signals/attribution/recovery` |
| `series --run r1grd4 --episode 43` | `decisions` 里每条有 `distance_to_goal / collision_count / plan_age / feedback_score` |

**通过标准**：以上字段齐备；`recovery_only=0.6635` 与 `guarded=0.7115` 与 `logs/route1/FINAL_TABLE.txt` **逐位一致**。

## 5. 用你的 key 做真实模型复验（10 分钟 + 一轮会话）

这一步把"确定性夹具模型"换成**真实大模型**，验证"模型自己会不会选中导航工具"。

### 5.1 配置 Provider（Agnes AI）

**路径 A（推荐，官方流程）**：浏览器打开实例的 Web 工作台 → 设置 → 模型 → 选 **Agnes AI** →
Base URL `https://api.agnes-ai.cn/v1` → 粘贴 key → **测试连接** → 在返回目录里选 `agnes-3.0-flash` → 保存。

只有 SSH 时，把服务器上的工作台映射到本机浏览器（**在你的 Windows 上开一个终端**）：

```powershell
# 服务器上先起工作台（已在 tmux 会话 agh_nav_web 里跑，端口 43120）
# 注意：实例的 daemon 与 Web 必须用同一个 origin，否则 serve 会报
#   "local daemon Web origin does not match the selected origin"
# 所以启动前两处都要带上 AGNES_WEB_ORIGIN=http://127.0.0.1:43120

# -L 左边=你本机的端口（挑空闲的，建议 43121）；右边=服务器上的 43120
ssh -i /srv/agh-demo\_tools\ssh\id_ed25519 -p 22 -N -L 43121:127.0.0.1:43120 your-user@your-server.example
# 保持这个终端窗口打开，然后浏览器访问 http://127.0.0.1:43121/
```

> ⚠️ **别用 43120 当本地端口**：开发机上 43120 被 DSH Desktop（也就是编辑器/工作台本体）占着，
> `ssh -L 43120:…` 会报 `bind [127.0.0.1]:43120: Permission denied`。
> 判断端口能不能用：`netstat -ano | findstr :43121`（应无输出）与
> `netsh int ipv4 show excludedportrange protocol=tcp`（落在预留段里也会 bind 失败）。
>
> ⚠️ 服务器上 **4177 是别人的实例**（`/srv/agh-demo/agnes-deploy/home`），不要占用、不要 kill。
> 我们的实例用 43120；`tmux kill-session -t agh_nav_web` 即可停掉工作台。

**路径 B（无浏览器，脚本）**：用仓库里的脚本走同一条 `config.test` + `config.save` 路径（脚本不打印 key）：

```bash
cd $SRC
AGH_HOME=$AGH_HOME corepack pnpm exec tsx agh-nav/tools/configure-provider.mts \
  --key-file /srv/agh-demo/.secrets/agnes-key.txt \
  --provider agnes-ai --model agnes-3.0-flash
# 期望输出：{"ok":true,"providerId":"agnes-ai","model":"agnes-3.0-flash","configured":true,...}（不含 key 明文）
node $SRC/packages/cli/dist/local/agnes.mjs doctor provider     # 期望：不再是 "no configured provider route selected"
```

失败时脚本会打印 AGH 的真实 reason 码并给中文解释（`config.save` 会**再测一次连接**并要求 `verified=true`，
所以 key 无效时必然被拒）：

| reason | 含义与处理 |
| --- | --- |
| `CONFIG_TEST_FAILED` | 测试连接没通过：key 无效/过期，或网关拒绝——换 key，或在 Web 上看「测试连接」的具体报错 |
| `CONFIG_MODEL_UNAVAILABLE` | 模型不在目录里；脚本会把候选模型打出来，用 `--model` 选一个 |
| `CONFIG_UNKNOWN_PROVIDER` | provider id 不对（Agnes AI 是 `agnes-ai`） |
| `CONFIG_CREDENTIAL_REQUIRED` / `CONFIG_CREDENTIAL_STORE` | key 没读到 / 凭据写不进实例 |
| `CONFIG_ENDPOINT_OVERRIDE_UNSUPPORTED` | 该 provider 不允许自定义 `baseUrl`：去掉 `--base-url` |
| `CONFIG_REVISION_CONFLICT` | 配置被别处同时改了：重跑即可 |

> 已知坑（2026-10-11 修）：早期版本的脚本把 `config.test` 的返回当成带 `baseUrl` 的对象，
> 结果给 `config.save` 传了空串 `baseUrl` —— 而 `ConfigSaveInput.baseUrl` 有 `minLength: 1`，
> 会被协议层直接拒掉。现在只在显式 `--base-url` 时才带上该字段。

### 5.2 三个真实请求（逐个跑，逐个核对）

```bash
CLI="node $SRC/packages/cli/dist/local/agnes.mjs"
cd $SRC
$CLI -p "列一下我们跑过哪些导航评估，并告诉我哪套恢复配置在 8 个场景上最稳"
$CLI -p "r1grd4 这个 run 里，碰撞密度和进度停滞两条通道会在哪些点要求重规划？覆盖多少失败回合？"
$CLI -p "把 r1grd4 的失败转成统一失败事件，按类型统计，并解释 N1 和 N5 的区别"
```

**判定标准（关键）**：不要看回答的文字，去 **看工具记录**：

```bash
$CLI sessions list            # 找到刚才的 session id
$CLI sessions show <id>       # 期望能看到 nav_list_runs / nav_recovery_options / nav_failure_events 的调用与结构化返回
```

| 判定项 | 通过 | 不通过 |
| --- | --- | --- |
| 模型是否**调用了**导航工具 | 工具记录里有 `nav_*` 调用 | 只有文字回答，没有任何工具调用 |
| 调用的参数是否合理 | 例如 `nav_recovery_options {run:"r1grd4"}` | 参数缺 `run`、或猜了不存在的 run |
| 返回是否是真实数据 | 例如 `fires_total`、`0.6635`、`route1.nav.channels` 与 §2 一致 | 数字与 §2 对不上 |
| 是否越权 | 只读工具不需要审批；`nav_run_eval` 必须弹审批 | 未审批就启动了评估（属于缺陷，请记录） |

### 5.3 真实模型复验的通过/不通过怎么写

- **通过**：三个请求里至少有两个选中了正确的工具、参数正确、返回与 §2 一致；`nav_run_eval` 在未被要求时不被调用。
- **部分通过**：模型选错工具或漏调工具（这是**模型能力问题，不是插件问题**）——
  这时请把 `sessions show <id>` 的原始记录一起保留，作为"工具面没问题、模型面待调"的证据。
- **不通过**：工具根本没注册（工具记录里 `nav_*` 一个都没有）→ 回到 §1.2 与 §4.2 定位。

## 10. 排障

| 现象 | 定位 | 处理 |
| --- | --- | --- |
| `package status` 里没有 `@agh-nav/*` | 装了但被禁用/被移除 | 参考 `README.md` §3.2.1 的 pty + capabilityHash + trust + enable 配方重装 |
| 工具报"实时数据面不可用" | ssh/本地探针失败 | 先跑 §1.1；看 `NAV_AGENT_*` 环境变量是否指向正确路径 |
| 看板一直"静态快照" | 同上的数据面问题 | 恢复后刷新页面；或让 Agent 再调一次 `nav_compare_configs` |
| AGH 源码构建在 Windows 上失败 | `build-native` 要 MSVC + Node headers | 本机没有编译器；**在服务器上构建**（见 README §6）。本地仍可跑 `ssh` 模式的插件自检 |
| 模型不调工具 | 先看 §4.2 是否 12/12（是→插件没问题），再看 §5.1 的 provider/model | 换更强模型或把请求写得更具体；把 `sessions show` 记录留档 |
| 一轮评估很久没结束 | GPU 排队或 tmux 会话 | `nav_env_status` 看 `eval_running`；`tmux ls` 看队列 |
| `doctor extensions` 报 `extension host assembly failed` | 这套源码构建上的既有现象（安装前后都一样，与我们的包无关） | 以 §4.2 的真实会话为依据，不要只看 doctor |
| `ssh -L` 报 `bind [127.0.0.1]:NNNNN: Permission denied` | 本机端口被占用或在系统预留段里 | 换成空闲端口（如 43121）：`netstat -ano \| findstr :43121`、`netsh int ipv4 show excludedportrange protocol=tcp`；43120 被 DSH Desktop 占用，别当本地端口 |
| `serve` 报 `EADDRINUSE 127.0.0.1:4177` | 4177 是**别人的**实例（`agnes-deploy/home`） | 我们的实例用 `--port 43120`，绝不 kill 别人的进程 |
| `serve` 报 `local daemon Web origin does not match the selected origin` | daemon 记的是旧 origin | 停掉 daemon，**同时**给 daemon 与 serve 带上 `AGNES_WEB_ORIGIN=http://127.0.0.1:43120` 重启 |
| `configure-provider` 报 `CONFIG_TEST_FAILED` | `config.save` 会再测一次连接并要求 `verified=true` | 换有效 key；或先在 Web 上看「测试连接」的具体报错 |
| 没有 TTY 时 `package add` 打印 "Installation cancelled" | AGH 设计如此：非交互不猜同意 | 用 `printf 'y\n' \| script -qec "…" /dev/null` 造 pty（README §3.2.1） |
