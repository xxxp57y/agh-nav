# 三步演示：在一个真实场景里，用自然语言把机器人走过去

> 目标：**90 秒内**让人看到"选场景 → 说人话 → 机器人真的走 → 画面和轨迹实时动 → 中途改派 → 自主完成"。
> 全部基于服务器上真实的 Habitat 场景与 navmesh 导航，不是动画。

---

## 0. 演示前 60 秒：把三样东西拉起来（只做一次）

## 第一幕：选场景、说指令、看它走（40 秒）

在 AGH 聊天里说：

> **这个场景里都有什么任务？**

Agent 调 `navlive_scenes` → 4 个场景（`2azQ1b91cZZ` / `QUCTc6BB5sX` / `TbHJrupSAjP` / `zsNo4HB9uLZ`），
每个 13 个回合，各自带真实指令（比如"走进客厅，一直走过客厅，再进入阳台下的入口"）。

> **在 2azQ1b91cZZ 里开一个任务，把客人从门口带到客厅尽头。**

Agent 调 `navlive_open` → 右侧**立刻出现第一人称画面与整层楼平面图**（带终点绿点）。
接着调 `navlive_goto` → **橙色轨迹开始长出来，机器人圆点朝目标移动**，
下方遥测同步刷新：剩余距离、已走步数、碰撞次数、plan_age。

**这一刻要强调的数字**（现场可复现）：一步 5–8 ms，一个回合 42–78 步，走到终点约 30–60 秒（8 Hz 实时循环）。

---

## 第二幕：中途改主意（20 秒）

机器人走到一半时说：

> **A 站暂时不能接收了，先去 C 站。**

Agent 再调一次 `navlive_goto` 换目标 → 事件流出现「**改派目标**」，
轨迹在当前位置拐弯，剩余距离按新目标重算。

**这一幕是全场的核心**：它证明"改主意"不是重跑回合、不是重启仿真，
而是**在同一个活着的环境里换目标**——这正是赛题要的"环境反馈后的自主任务调整"。

---

## 第三幕：自主收口 + 如实汇报（30 秒）

> **它现在到哪了？**

Agent 调 `navlive_state` → 用一句人话说清：位置、剩余距离、碰撞、走到第几步、最近事件。

> **跑完这一轮，把过程总结给我。**

Agent 收口成一句可核对的话：**成功 / 剩余 0.42 m / 碰撞 0 次 / 用一个回合**。

## 演示时最容易被问到的问题（提前准备好答案）

| 问题 | 答 |
| --- | --- |
| 这是录播吗？ | 不是。`navlive_goto` 之后轨迹、位姿、剩余距离都在变；问它"到哪了"得到的是当前值。可以现场让它改派到任意坐标验证。 |
| 谁在走路？ | `habitat.tasks.nav.shortest_path_follower` 在真实 navmesh 上逐点寻路（5–8 ms/步）。**它只回答"怎么走"，不回答"这句话该去哪"**——后者现在由 Agent 换算坐标，下一步接 VLA。 |
| 画面是渲染出来的还是图？ | Habitat 真的渲染（480×640 RGB），服务端 5 fps 编码成 JPEG；楼层图是 habitat 的 TopDownMap 测量项（1024 分辨率）。 |
| 为什么楼层图不是黑的？ | 因为过了 `colorize_topdown_map`（语义索引图直接当灰度图存会全黑），且关掉了 fog of war。这两点都踩过坑，写在 `docs/实时可视化工作台.md` §7。 |
| 换个场景要多久？ | 换场景 8–20 s（重载 `.glb`），同场景换回合约 3 s。 |
| 中途说"停一下"呢？ | `navlive_pause` 让它原地停住（画面继续刷新），`navlive_resume` 继续走向当前目标。 |
